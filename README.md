# Advanced House Price Prediction

A machine learning project that analyzes housing data and predicts house prices using regression algorithms.

## Overview
This project explores housing data through statistical analysis and visualization, followed by preprocessing and regression model development to predict house prices.

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

## Workflow
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Outlier detection
- Correlation analysis
- Model training and evaluation

## Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Evaluation Metrics
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- R² Score
